## ルート

| パス | 内容 |
|------|------|
| `/` | 質問リンク作成（`?create=1` で自動作成） |
| `/history` | 送信履歴（この端末で作った質問） |
| `/q/:id` | 相手が答えるページ（端末ごとに独立した回答） |
| `/watch/:id` | 集計・確認ページ |
| `/s/:questionId` | 結果シェアページ（OGP対応、`?r=` で個別回答） |
| `/demo` | 保存なしのお試し |

## データモデル（シンプル・同時利用対応）

- **質問 (question)**: `data/questions/{questionId}.json` に1ファイルずつ保存。別ユーザーの質問とファイルが混ざらない。
- **回答 (response)**: 質問内の `responses[responseId]` に**追記のみ**。更新は questionId ごとに直列化し、同時回答でも上書きしない。
- **送信履歴**: 作成者端末の localStorage（サーバーに作成者情報は保存しない）。
- サーバーのデータは一時的。30日未更新で掃除。
- 二重回答は不可（同じ端末の responseId では既存結果を再表示）。

## シェア

回答後・確認ページから「結果をシェア」できます。カードには **YES/NO とアプリ名だけ** が含まれ、個人を特定する情報は入りません。

- モバイル: Web Share API（画像＋リンク）
- X / LINE ボタン、リンクコピー
- `/s/:questionId` を貼ると OGP 画像がプレビュー表示されます
